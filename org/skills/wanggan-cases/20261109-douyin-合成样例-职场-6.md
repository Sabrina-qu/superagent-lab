# 案例：会议开不完，不是因为事多，是因为没写结论

## 钩子（前 3 秒/首段）

原句: "你有没有一天开四个会，散会啥也没定。"
为什么算钩子：用"你有没有"直接提问，把职场人一周内反复遭遇的具体场景（连轴开会、散会无结论）3 秒内怼到脸上，痛点即代入，观众立刻对号入座。

## 情绪曲线

- 钩子（句 1）：提问代入"会多且无产出"的职场痛点，情绪低位起笔；
- 铺垫（句 2）："一周九个会、项目还在原地"自曝数据，痛感加重，情绪继续下探；
- 转折（句 3–4）："只改了一个流程——散会前十分钟写三条结论"+"做什么/谁负责/哪天交"给出可照抄的极简解法，情绪触底回升；
- 结果（句 5）："会议数没变，但返工明显少了"用对照兑现效果，情绪上行；
- 金句（句 6）：收在反转断言"会议病不是会太多，是散会没有落字"上，情绪封顶。
- 整体走势：痛点下探 → 流程反转 → 结果兑现 → 断言收尾，对应词表「反转」。
