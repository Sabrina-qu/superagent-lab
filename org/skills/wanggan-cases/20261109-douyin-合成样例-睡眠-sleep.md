# 案例：睡不好不是因为压力大，是因为你上床太早

## 钩子（前 3 秒/首段）

原句: "你有没有发现，越想早睡越睡不着。"
为什么算钩子：用一句提问直接把"努力早睡反而失眠"的反常识矛盾抛给观众，失眠人群 3 秒内对号入座，越想解决越解决不了的无力感即钩子。

## 情绪曲线

- 钩子（句 1）：提问抛出"越早睡越睡不着"的矛盾，痛点直击，情绪低位起笔；
- 铺垫（句 2）："十点躺下，刷手机刷到一点半"自曝黑历史，共鸣加深，情绪继续下探；
- 转折（句 3）："只改了一件事——把上床时间推迟到十一点半"，给出反直觉的极简解法，情绪触底回升；
- 上升（句 4–5）：第一周二十分钟内睡着 → 七点自然醒 → 每天睡够七小时，结果逐级兑现；
- 金句（句 6）：收在反转断言上，情绪封顶。
- 整体走势：痛点下探 → 解法反转 → 结果上行，对应词表「反转」。
