# 案例：家里乱不是东西多，是每个抽屉都没名字

## 钩子（前 3 秒/首段）

原句: "你有没有收拾一下午，三天后又乱回去。"
为什么算钩子：用一句直接提问把观众拉进"收拾了又乱"的具体日常场景，3 秒内完成身份代入，收纳反复失败的痛点即钩子。

## 情绪曲线

- 钩子（句 1）：提问代入收拾后又乱回去的痛点，情绪低位起笔；
- 铺垫（句 2）："玄关堆了七八样东西，钥匙永远找不到"自曝家中细节，共鸣加深，情绪继续下探；
- 转折（句 3）："只做一件事——每个抽屉贴一张标签"，给出极简解法，情绪触底回升；
- 上升（句 4–5）：标签写清放什么、谁负责、多久清一次 → 三个月后找钥匙不超过十秒，做法与结果对照兑现；
- 金句（句 6）：收在反转断言上，情绪封顶。
- 整体走势：痛点下探 → 解法反转 → 结果上行，对应词表「反转」。
