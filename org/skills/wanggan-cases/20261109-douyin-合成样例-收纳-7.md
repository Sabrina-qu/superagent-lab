# 案例：家里乱不是东西多，是每个抽屉都没名字

## 钩子（前 3 秒/首段）

原句: "你有没有收拾一下午，三天后又乱回去。"
为什么算钩子：用一句直接提问把观众拉回自己反复经历的挫败场景（收拾完又乱），3 秒内完成身份代入；先让人点头"我家就这样"，痛点即钩子。

## 情绪曲线

- 钩子（句 1）：提问切入"三天后又乱回去"的挫败感，情绪低位起笔；
- 铺垫（句 2）："玄关堆了七八样东西，钥匙永远找不到"，把乱具体化到每天的高频痛点，共鸣加深、情绪继续下探；
- 转折（句 3）："只做一件事——每个抽屉贴一张标签"，给出极简解法，情绪触底回升；
- 上升（句 4–5）：标签三要素（放什么、谁负责、多久清一次）给出可复制动作，再用"找钥匙没超过十秒"兑现结果，可信度拉满；
- 金句（句 6）：反转断言收尾，情绪封顶。
- 整体走势：痛点下探 → 极简解法 → 结果上行 → 断言收尾，对应词表「反转」。
