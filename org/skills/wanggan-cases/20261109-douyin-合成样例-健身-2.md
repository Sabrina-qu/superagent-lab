# 案例：减脂不用跑步，先把你家椅子搬走

## 钩子（前 3 秒/首段）

原句: "你有没有过这种减肥：办了年卡去了三次。"
为什么算钩子：用直接提问点名"办卡不去"的普遍尴尬，3 秒内让观众对号入座，痛点即钩子。

## 情绪曲线

- 钩子（句 1）：提问代入"办卡不去"痛点，情绪低位起笔；
- 铺垫（句 2）："三千块办卡只去五次"自曝具体损失，共鸣加深，情绪继续下探；
- 转折（句 3）："只做一件事——把客厅椅子搬进储物间"，给出反常识极简解法，情绪触底回升；
- 上升（句 4–5）：一天多站三小时 → 三个月掉八斤、没节食没再进健身房，结果逐级兑现；
- 金句（句 6）：收在反转断言上，情绪封顶。
- 整体走势：痛点下探 → 反常识解法 → 结果上行，对应词表「反转」。
