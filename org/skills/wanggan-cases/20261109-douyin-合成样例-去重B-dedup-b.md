# 案例：存钱不是省钱，是先自动转走

## 钩子（前 3 秒/首段）

原句: "我以前每个月都想省钱，结果月底还是没剩下。"
为什么算钩子：用"想省钱却剩不下"的月光痛点自白开场，直接命中目标人群的共同经历，观众立刻对号入座。

## 情绪曲线

- 钩子（句 1）：痛点直击，自曝"想省钱却剩不下"，情绪低位起笔；
- 转折（句 2）："改了顺序——发工资当天先自动转走一笔"，给出极简解法，情绪触底回升；
- 铺垫（句 3）："转走的钱我当它不存在，只花剩下的"，交代执行心法，情绪平稳上行；
- 兑现（句 4）：第一个月难受 → 第三个月开始忘记它存在，代价与适应过程对照，可信度增强；
- 金句（句 5–6）："存钱靠的不是忍，是顺序""让你存不下的不是收入，是先花后存"，双重反转断言收尾，情绪封顶。
- 整体走势：痛点下探 → 解法反转 → 双重金句收束，对应词表「反转」。

## 金句位置

原句: "真的，让你存不下的不是收入，是先花后存。"
