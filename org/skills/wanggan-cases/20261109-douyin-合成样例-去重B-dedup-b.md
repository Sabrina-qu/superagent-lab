# 案例：存钱不是省钱，是先自动转走

## 钩子（前 3 秒/首段）

原句: "我以前每个月都想省钱，结果月底还是没剩下。"
为什么算钩子：用"想省钱却剩不下"的普遍窘境直戳月光痛点，"结果还是没剩下"给出落差，3 秒内让观众对号入座、想知道怎么破。

## 情绪曲线

- 钩子（句 1）：抛"想省钱却存不下"的痛点，情绪低位起笔；
- 转折（句 2–3）："改了顺序——发工资当天先自动转走一笔""当它不存在，只花剩下的"，给出极简解法，情绪触底回升；
- 递进（句 4）："第一个月有点难受，第三个月开始忘记它存在"，用时间轴兑现适应过程，共鸣加深、情绪上行；
- 金句（句 5–6）：连续两句反转断言收束，情绪封顶。
- 整体走势：痛点下探 → 顺序反转 → 结果上行，对应词表「反转」。

## 金句位置

原句: "真的，让你存不下的不是收入，是先花后存。"
位置：后1/3（全文第 6/6 句，结尾压轴，金句即收尾；与句 5"存钱靠的不是忍，是顺序"构成双金句收束）

## CTA 手法

无CTA。全文停在金句上，没有引导关注、评论引导或下集预告；互动靠"先存后花"的争议性（"转走了急用怎么办""第二天又转回来了"）在评论区自然发酵。
