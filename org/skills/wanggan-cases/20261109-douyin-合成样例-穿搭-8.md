# 案例：显瘦不靠减肥，先把上衣塞进去

## 钩子（前 3 秒/首段）

原句: "你有没有那种衣服，穿上去像胖了五斤。"
为什么算钩子：用"你有没有"直接提问，把"一穿就显胖"这件每个买衣服的人都踩过的坑 3 秒内怼到脸上，痛点即代入，观众立刻开始回想自己衣柜里那件"显胖五斤"的衣服。

## 情绪曲线

- 钩子（句 1）：提问代入"衣服显胖"的普遍痛点，情绪低位起笔；
- 铺垫（句 2）："身高一五八、照片里总是五五分"自曝身材短板，小个子观众瞬间对号入座，情绪继续下探；
- 转折（句 3–4）："只改一个动作——把上衣塞进裤腰"+腰线一出来视觉高三厘米，给出零成本极简解法并即时兑现效果，情绪触底回升；
- 结果（句 5）：买衣服的标准从"版型"换成"能不能塞"，行为标准被改写，情绪继续上行；
- 金句（句 6）：收在反转断言"显瘦不靠体重，靠腰线"上，把解法升维成方法论，情绪封顶。
- 整体走势：痛点下探 → 动作反转 → 即时兑现 → 断言收尾，对应词表「反转」。
