# 案例：存不下钱不是因为赚得少，是因为先花再存

## 钩子（前 3 秒/首段）

原句: "你有没有月底一看余额，又只剩三位数。"
为什么算钩子：用一句直接提问把观众拽进"月底查余额"的具体场景，"只剩三位数"给出人人可自检的痛感标准，3 秒内完成身份代入，痛点即钩子。

## 情绪曲线

- 钩子（句 1）：提问代入月底余额痛点，情绪低位起笔；
- 铺垫（句 2）："月薪一万二"与"三年存款不到五千"自曝反差，焦虑加深，情绪继续下探；
- 转折（句 3）："只改了一个顺序——发工资当天先转走两千"，给出零门槛解法，情绪触底回升；
- 上行（句 4–5）：第一个月外卖从三十降到十五的痛感，对冲一年后"账户躺着两万四、生活没变差"的结果，代价→收益逐级兑现；
- 金句（句 6）：收在反转断言上，情绪封顶。
- 整体走势：痛点下探 → 顺序反转 → 结果上行，对应词表「反转」。
