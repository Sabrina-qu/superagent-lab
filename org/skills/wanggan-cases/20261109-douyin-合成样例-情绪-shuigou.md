# 案例：情绪稳定不是修养好，是你睡够了

## 钩子（前 3 秒/首段）

原句: "你有没有发现，熬夜第二天特别容易炸。"
为什么算钩子：用"你有没有发现"直接提问，把观众拽进熬夜后情绪失控的具体场景，3 秒内完成身份代入，痛点即钩子。

## 情绪曲线

- 钩子（句 1）：提问代入"熬夜容易炸"的痛点，情绪低位起笔；
- 铺垫（句 2）：自曝"总怪自己脾气差"，把错误归因摆出来，共鸣加深，并引出"记了一个月睡眠"的动作；
- 转折（句 3–4）：睡不足六小时"天天吵架"与睡够七小时"笑着回"形成同件事两种反应的对照，归因开始翻转；
- 收束（句 5）：给出方法论"先看睡眠，再谈情绪管理"，情绪随掌控感回升；
- 金句（句 6）：收在反转断言"不是性格，是没睡够"上，情绪封顶。
- 整体走势：痛点下探 → 对照反转 → 归因重塑，对应词表「反转」。
