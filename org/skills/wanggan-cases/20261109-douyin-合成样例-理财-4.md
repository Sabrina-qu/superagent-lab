# 案例：存不下钱不是因为赚得少，是因为先花再存

## 钩子（前 3 秒/首段）

原句: "你有没有月底一看余额，又只剩三位数。"
为什么算钩子：用一句直接提问把观众拉进月底看余额的具体场景，"只剩三位数"精准戳中月光痛点，3 秒内完成身份代入。

## 情绪曲线

- 钩子（句 1）：提问代入月底没钱的痛点，情绪低位起笔；
- 铺垫（句 2）："月薪一万二，工作三年存款不到五千"自曝收入与存款的反差，共鸣加深，情绪继续下探；
- 转折（句 3）："只改了一个顺序——发工资当天先转走两千"，给出极简解法，情绪触底回升；
- 上升（句 4–5）：第一个月外卖降级很痛 → 一年后账户躺着两万四且生活没变差，代价与结果对照兑现；
- 金句（句 6）：收在反转断言上，情绪封顶。
- 整体走势：痛点下探 → 解法反转 → 结果上行，对应词表「反转」。
