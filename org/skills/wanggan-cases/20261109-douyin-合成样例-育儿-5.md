# 案例：孩子不写作业，先别催，把桌子清空

## 钩子（前 3 秒/首段）

原句: "你有没有陪写过作业，从七点吼到十点。"
为什么算钩子：一句直接提问瞬间锁定目标人群（陪写作业的家长），"从七点吼到十点"给出极端具体的痛苦细节，3 秒内完成身份代入，痛点即钩子。

## 情绪曲线

- 钩子（句 1）：提问代入陪写痛点，情绪低位起笔；
- 铺垫（句 2）："写十分钟能摸二十分钟橡皮"自曝孩子磨蹭，共鸣加深，痛点继续下探；
- 转折（句 3）："只做了一件事——书桌上只留当科作业和一支笔"，给出极简解法，情绪触底回升；
- 上升（句 4–5）：第一周找借口要喝水 → 第二周四十分钟写完 → 孩子自己收拾桌面，结果逐级兑现；
- 金句（句 6）：收在反转断言上，情绪封顶。
- 整体走势：痛点下探 → 解法反转 → 结果上行，对应词表「反转」。
