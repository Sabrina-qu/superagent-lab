# 网感评分宪法 v0（骨架待生效）

> 状态：**v1 已生效**（2026-11-10 老板确认默认权重）
> 评分对象：单篇内容稿（脚本/图文文案）。每篇 ≤ 2 分钟打完。

## 五项成分（各 0-10 分）

### 1. 热点敏感度
稿件是否踩到过去 48 小时在涨的话题。
- 0 分锚点：与任何在涨话题无关，或蹭的是 ≥7 天前的冷饭。
- 10 分锚点：踩在上升期的赛道相关热点上，且角度有增量信息，不是复读。
- 可脚本化：与 trend-watcher 热点库比对（抓取时间必须 <48h）。

### 2. 平台腔
目标平台（当前主平台：**抖音**（2026-11-10 定））的句式密度、emoji 密度、分段节奏是否对味。
- 0 分锚点：读起来像公众号公文/新闻通稿。
- 10 分锚点： native 用户一眼认亲，句长/emoji/分段全在平台典型区间内。
- 可脚本化：`org/verify/check-wanggan.py` 输出硬指标（平均句长、emoji 密度、分段数、钩子存在性），阈值在 Week 1 用 50 篇 case 校准后填进脚本常量。

### 3. 梗库运用
用了当代梗还是过期梗。
- 0 分锚点：用过期梗或硬造梗。
- 10 分锚点：用 `org/skills/meme-bank.md` 在有效期内、与语境贴合的梗。
- 半衰期校验：meme-bank 每条标注预测失效日，过期即标灰。

### 4. 情绪节奏
钩子（前 3 秒/首段）、转折、金句位置是否符合爆款结构。
- 0 分锚点：平铺直叙，前 3 秒无钩子。
- 10 分锚点：钩子-铺垫-转折-金句-CTA 齐全且节奏符合案例库主流结构。
- 结构标记：拆解时打标（见 case 模板），仿写稿对照自查。

### 5. 受众同理
能否预测评论区最常见的三种反应。
- 0 分锚点：预判的三种反应与实际评论区零重合。
- 10 分锚点：三种反应预测中至少两种与实际高赞评论同向。
- 最难成分，靠盲测与实测回归校准，不脚本化。

## 评分程序
1. 先跑 `org/verify/check-wanggan.py`，硬指标不过 = 平台腔直接 ≤3 分，可退回重写；
2. 人工五项各打 0-10 整数分；
3. 每篇只写**一条**最重要的问题（≤30 字）；
4. 总分 = Σ(成分分 × 权重)；≥8 分稿进入盲测候选池；
5. 任何一项 ≤3 分，触发"回看对应 case 重写"，不进入平均分统计。

## 修订纪律
-  proposals：bot 在 PR 里提议修改锚点描述/阈值，附 ≥5 条 evidence（具体稿件+分数）；
-  批准：老板在 PR 回复"批准"或线下确认后，才改本文件；
-  版本：每次修订 bump 版本号（v1、v2…）并在文末记修订日志。
